  • Wisp

    Wisp is a lightweight context-aware UI styling engine that adapts interface presentation dynamically based on semantic context instead of rigid CSS rules. It enables cleaner interfaces and more intelligent styling behaviour in web applications.

    Repository

  • Weave

    Weave is a natural language driven system for generating structured semantic HTML. It introduces a declarative DSL that allows developers to transform human intent directly into machine-readable markup for faster interface development and content creation.

    Repository
    npm package

  • ContextFusion

    ContextFusion acts as the context brain for LLM applications. It compresses, ranks, and routes the most relevant pieces of information to chat and agent models, helping AI systems make better decisions using the right evidence. It supports ecosystems including OpenAI, Claude, Ollama, and MCP.

    Repository
    npm package

  • DermaScanAI

    DermaScanAI is an AI-powered dermatology analysis tool designed to assist in evaluating skin lesion images. It leverages machine learning models to support screening and early identification of dermatological conditions.
